# Проверка Nominatim

Запуск с Python 3, без дополнительных библиотек:

```bash
python3 check_geocoder.py
```

Скрипт делает пять последовательных запросов обратного геокодирования для
координат Москвы, выводит HTTP-код, время ответа и адрес. Между запросами
выдерживается пауза 1,1 секунды. При HTTP 403 или 429 проверка прекращается.

Это проверка доступности сервиса, а не нагрузочный тест и не доказательство
работы серверного ограничителя. Отсутствие HTTP 429 не означает отсутствия
лимита. Публичный Nominatim требует не более одного запроса в секунду;
повторные координаты в реальном приложении следует кешировать.
